One company, three operating segments, one shared console.

This github.io surface is the internal operating console for Thomas and the autonomous organization. It is not the public company website.

Surfaces

elephantharbor.com — Public company site. Owned by Harbor Presence.

elephantharbor.github.io — Portfolio operating console (shell: Portfolio Systems). Segment desks are linked rooms.

Segments

Portfolio layer

Hayes (Portfolio - CEO) — Portfolio structure, cross-segment priorities, conventions.

Wells (Portfolio - Systems) — Shared shell, design system, navigation, segment-summary contract, Needs Your Attention presentation.

Segments own their canonical data and detailed dashboards. Portfolio Systems owns the framework and visual language.

Data flow

Segment canonical state → segment-summary.json → portfolio homepage tiles + Needs Your Attention.

Design system source: /shared/eh-console.css (do not fork tokens across desks).

Adding a future segment

  1. Register the segment and publish a standard summary.
  2. Ship a desk URL under the shared design system + way-home nav.
  3. Add a portfolio tile/nav entry — no redesign of the shell.
