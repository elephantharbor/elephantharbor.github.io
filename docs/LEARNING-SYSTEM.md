# Elephant Harbor Learning System (OS v2)

**Issued:** 2026-09-16 by Thomas via Hayes  
**Status:** Durable canon  
**Companion:** [OS-V2-DOCTRINE.md](OS-V2-DOCTRINE.md) Principle 6

Replace informal “Lessons Learned” notes with a closed loop. Structured fields over essays.

## Closed loop

`Observation → Hypothesis/Lesson → Behavioral Change → Test → Result → Reinforce / Modify / Reject → Institutionalize`

## Lifecycle statuses

`Candidate → Testing → Confirmed → Institutionalized → Weakening → Superseded / Rejected`

## Required fields

- Observation
- Supporting evidence (+ contradicting evidence when present)
- Date / evidence window (**origination date** required)
- Scope (structural vs contextual/temporal)
- Hypothesis
- Confidence / strength (sample size + recency)
- **Required behavioral change** (mandatory — “what we do differently now”)
- Owner
- Test / validation method
- Metrics
- Review / expiration date
- Last validated date
- Outcome
- Current status
- Durable primitive affected (skill, routine, threshold, agent description, scanner, workflow, etc.)

## Strength, decay, expiry

- **Structural** lessons (e.g. API always needs auth) may persist with periodic validation.
- **Contextual/temporal** lessons (market regime, sports tendency, engagement style, conversion pattern) must support reinforce → weaken → supersede → retire. Never permanent dogma from a thin sample.
- Avoid overreacting to single observations; require enough sample/recency for status moves.

## Behavior consequence rule

Every lesson needs an explicit behavior consequence. Recording “X gets no engagement” is incomplete — pair with next-behavior change and measurement window. A lesson with no behavioral implication does not belong.

## Before consequential decisions

Consult relevant Confirmed / Institutionalized / Testing lessons in scope. If an unchanged process has repeated zero outcomes, open or escalate a Candidate lesson about the **process**.

## Desk sync + anti-bureaucracy

Material lesson status changes update the operating desk Learning section **same turn**. Prefer short structured records. No paperwork whose only purpose is proving process occurred.
