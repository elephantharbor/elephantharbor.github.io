## Ladder

`Observe → Nominate → Cheap Test → Small Live Experiment → Scale → Exit`

Applies across Capital, Foundry, Presence, Local.

## Graduated certainty

- Certainty required rises with cost, risk, and irreversibility.
- Cheap tests do not require full-scale proof.
- Commitment size and proof bar move together — not before.

## Decision vocabulary

Every serious candidate eventually gets: **ACT / TEST SMALL / WATCH / REJECT** with concise reasoning.

## Zero-output threshold review

If a pipeline repeatedly returns examined → 0 advanced (or equivalent), treat that as evidence about the **process**, not only about candidates. Trigger threshold / sourcing / universe / scanner / challenge / team review **same cycle** — do not merely report another empty result.

Repeated WATCH/REJECT with an unchanged process triggers the same review.

## Tracking (where pipelines exist)

Track roughly: discovered → evaluated → nominated → tested → activated → successful. Persistently zero advancement rate is process evidence.
